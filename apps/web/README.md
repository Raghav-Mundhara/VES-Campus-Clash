# apps/web — VES Campus Clash Frontend

React + Vite + TypeScript + TailwindCSS

## Dev

```bash
npm install
npm run dev        # starts Vite dev server on :5173
```

## Notes

- `/api/*` requests are proxied to `http://localhost:3001` during development via `vite.config.ts`.
- Pages (Landing, Register, Game, Result) will be added in subsequent prompts.
